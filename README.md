# 掀開水岸新頁｜互動教學網頁 v1.0

## 這一版包含
1. 首頁：葫蘆墩圳／水岸花都介紹＋使用者提供的照片。
2. 時間軸：1980 停車場 → 2016 掀蓋 → 現今水岸花都。
3. 永續城市：SDG 11＋透水磚、生態工法、水撲滿、生態草溝、箱涵＋米、餅、柴。
4. 互動設計地圖：
   - 可切換「街道圖／衛星圖」
   - 工具箱選擇設施
   - 點擊地圖放置
   - 圖示可拖曳微調
   - 只允許放在「水岸花都」與「後方尚未動工區」
   - 不判斷對錯
   - 完成後產生小組發表提示

## 開啟方式
最簡單：
- 直接雙擊 `index.html`。
- 若瀏覽器因安全限制不允許地圖圖磚載入，可用 VS Code 的 Live Server，
  或在資料夾中執行：
  `python -m http.server 8000`
  然後開啟 `http://localhost:8000`

## 之後最常需要修改的位置
### 1. 改文字
直接編輯 `index.html`。

### 2. 改首頁照片
把新的圖片命名為 `hero.png`，放進本資料夾覆蓋原檔即可。

### 3. 改地圖中心
編輯 `script.js`：
`const center = [24.25655, 120.71455];`

### 4. 改「可以設計的範圍」
編輯 `script.js` 裡的：
- `const currentZone = [...]`
- `const futureZone = [...]`

這兩個是「教學示意範圍」，不是工程測量界線。
如果你們之後拿到更精確的衛星圖或老師提供的範圍，只需要替換座標。

### 5. 新增設施
編輯 `facilityData`：
`{ id:"xxx", icon:"🌳", name:"樹木", desc:"綠地" }`

## 地圖來源
- 街道圖：OpenStreetMap
- 衛星圖：Esri World Imagery
兩者都是外部網路圖磚，因此正式試教時需要有網路。

## 設計理念
本版本刻意不設「正確答案」。學生完成空間配置後，直接進入小組發表：
「我們在哪裡放了什麼？為什麼？它和水、安全、環境或在地文化有什麼關係？」

這是為了配合你們目前的試教流程，而不是做成遊戲式的對錯判定。


## 如果雙擊 index.html 後按鈕仍沒有反應
建議不要直接用 `file://` 開啟，改用本機伺服器：

### Windows 最簡單方法
1. 把整個資料夾解壓縮。
2. 在資料夾空白處按右鍵 → 在終端機中開啟。
3. 輸入：
   `python -m http.server 8000`
4. 瀏覽器輸入：
   `http://localhost:8000`

如果電腦沒有 Python，也可以用 VS Code 安裝 Live Server，右鍵 `index.html` → Open with Live Server。


## v1 修正版 2：地圖底圖顯示修正
如果第四頁只顯示左上角一小塊底圖，原因是 Leaflet 在第四頁尚未顯示時就先建立地圖，
造成它一開始把容器尺寸判成很小。這版已修正成共用同一個 map instance，
切換到第四頁時會執行 `map.invalidateSize()`，讓底圖重新填滿整個地圖區域。

另外，OpenStreetMap 改用官方目前指定的：
`https://tile.openstreetmap.org/{z}/{x}/{y}.png`
官方政策要求使用 HTTPS 與正確 attribution。
